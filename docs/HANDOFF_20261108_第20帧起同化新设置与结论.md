## 3. 结果与结论（测试集，`outputs/261107_first20_test/`）
选定参数（验证集，`outputs/261107_sweep_first20/selection.txt`）：DPS `bg_std` K=10 取 **0.4**、K=30 取 **0.5**；EnKF 膨胀 K=10 取 **2.0**、K=30 取 **5.0**。

| K | 扩散同化 | EnKF | 纯预报 | DPS 比 EnKF 低 | DPS 更优 | 差值 95% CI（case 为单位 bootstrap） |
|---|---|---|---|---|---|---|
| 10 | 0.0250 | 0.0320 | 0.1729 | 22% | 60/60 run，20/20 case | [−0.0073, −0.0068] |
| 30（去掉 6 个发散 run 后） | 0.0326 | 0.0409 | 0.1729 | 20% | 53/54 run，19/20 case | [−0.0095, −0.0062] |
| 30（全部 60 run） | **0.0470** | 0.0409 | 0.1729 | −15%（DPS 反而更差） | 53/60 | — |

- 三个种子方向一致：DPS/EnKF 在 K=10 为 0.77/0.76/0.82，K=30 为 0.75/0.80/0.84。
- 散度（相对散度，Chebyshev 谱导数）：投影后 DPS 与 EnKF 都是 1.3e-7；原始输出约 1e-5（DPS 1.0e-5、EnKF 9.3e-6）；真值 3.9e-5。方法间无可见差异。
- **K=30 的前提必须写进报告**：DPS 在 60 个 run 里有 **6 个发散**（10%），分别是 (种子,case)=(42,0)、(42,7)、(43,7)、(43,10)、(43,14)、(44,14)，误差 0.12–0.19，到第 599 帧仍 0.15；EnKF 无一发散。用户让“坏的不要”，所以上表主结论按去掉发散 run 给，但**去掉了多少、为什么去掉要明写**；不去掉则 K=30 时 DPS 均值（0.0470）差于 EnKF（0.0409）。K=10 无发散。
- 发散原因是**推测**：`bg_std=0.5` 偏小，验证集只有 5 个 case × 1 个种子（K=30 的 0.5 未出现发散），测试集 60 个 run 才暴露。没有在测试集上对 `bg_std` 做对照。

## 4. 本轮的重要发现（按重要性）
1. **DPS 的背景权重要随背景质量调**。起点背景（donor 状态）误差约 0.19，是坏背景。验证集 `bg_std`（观测/背景权重由 `obs_std=.05`、`bg_std` 决定，原值 0.3）：0.3 时有 case 卡在坏背景（K=10 全局 0.087，K=30 0.104）；调到 0.4–1 后恢复。越小越准但越容易有 case 发散，存在临界点（K=10 的临界在 0.3–0.4 之间）。**选参不能只看均值，要看有没有发散 run**。（早先在“第 0 帧用 donor 末帧同化”设置下的 `outputs/261107_sweep_bgstd` 也是这个现象。）
2. **EnKF 的预热仍是几百帧**：test case 0 上约 200–300 帧才降到稳定水平；DPS 在约 100 帧内降到 0.02–0.03（K=10）。
3. **测试集状态离训练集很近**：20 个测试 case 的第 0 帧，在 16000 个训练帧里都能找到很相近的帧，最近距离平均 0.028（0.007–0.064），而随机两个训练帧是 0.199。所以 DPS 的好成绩有一部分来自先验覆盖了这类流场，报告里要写。训练/测试是否用了不同随机种子**没有核对**（`data/processed_600/seedmap.json` 里 test 种子从 81 起，训练种子无记录）。
4. **EnKF 在同化间隔后段会反超 DPS 的个别帧**：DPS 同化后误差随预报回升，EnKF 在间隔内较平；K=30 时 EnKF 更好的帧占 22%（旧设置数据，新设置未重算）。EnKF 为什么更平只是推测。
5. 预热 20 帧对旧设置（第 0 帧观测重建）的 400–599 帧结果几乎无影响（逐 run 差 1e-6 量级）。
