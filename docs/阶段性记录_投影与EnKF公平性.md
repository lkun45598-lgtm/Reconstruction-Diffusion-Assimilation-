## 2. 已经做完的事和结论

### 2.1 核对（不是问题的）
- EnKF 的 R：用已保存的 EnKF 分析场做逐位重算，主对比用的就是**标准差 0.1（R=0.01）**，膨胀 1.1，局地化 1.5×1.2，初始扰动 0.1，20 成员。命令行默认值（0.05 等）没有被用到。
- 起点公平：EnKF 以 A 的第 0 帧分析为中心（不是真值），跳过自己的 t=0 更新。
- 推理代码、checkpoint 配置、归一化三个先验完全相同；新增数据与旧数据同分布。
- 旧脚本 `scripts_long_run.sh`（10-18 的无噪声长时程）传的是 `--enkf-obs-std 0.01`（若当标准差即 R=1e-4）、膨胀 2.5，引用那批旧结果要留意。

### 2.2 加数据 / 加大先验：没有收益（负结果）
- 新增 400 个 case（seed 200–599，`data/rb_extra_raw`，`data/processed_v2` 共 560 train，val/test 同旧）。在 `10.16.46.215:/mnt/disk_e/lz/RB_Diffusion_DA_v2` 上 8 卡训练（c16 约 20 分钟级，c32 更久），结果复制回 `outputs/rb_prior_v2/`、`outputs/rb_prior_v2_c32/`。
- 验证损失 0.0435（旧）→ 0.0284（c16）→ 0.0251（c32），但验证 case 0 的循环 RMSE 反而变差：0.0167（旧，3 种子均值）→ 0.0179 → 0.0197。
- 81 组 (bg_std, dps_rate, obs_std) 重扫，三个先验的最优都是原参数 0.3/2/0.05，所以不是参数不匹配。单步实验（背景用真值预报一帧）里新先验在噪声观测下不比旧的差，所以**原因没找到**（可能与循环累积有关，只是推测）。
- 数据本身：RB 状态种类很少（约 77% 能量在 kx=2，相邻帧相关 0.998），加 case 只让验证帧到最近训练帧的距离近了约 18%。
- **决定：主线继续用旧先验 `outputs/rb_prior_4gpu/best.pt`，不重训。**

### 2.3 DPS 观测权重软化（`obs_soft`）：放弃
- γ_t=1/(R+s·σ_t²)。单步变好（0.0099→0.0052），循环里变差（第 0 帧没有背景，弱引导起步误差 0.116，要 60 帧恢复）。**教训：只看单步会误导，必须在循环里验证。** 开关保留，默认 0。

### 2.4 无散度 + 无滑移投影（本阶段最主要的产出）
- 纠正了一个错误：`z` 是 Chebyshev–Gauss 内部节点，`argmin(z)`/`argmax(z)` 不是真壁面。早先报的"壁面速度"是最近内部节点速度。真壁面要用谱插值到 z=0, Lz。`forecast_solver.py` 里 `vx[:, [low, high]] = 0` 同样是在把内部节点当壁面置零，**尚未单独核查其影响**。
- 新投影 `src/rdda/solver/no_slip_projection.py`：带包络流函数基（ψ 和 ∂zψ 在真壁面为 0）+ 与 `rb_balance` 一致的 Chebyshev 谱导数，`ridge=0`，`modes=16`。float64 下散度 1.5e-15、真壁面 5e-14；稠密矩阵版本对称、幂等（是正交投影）。
- 对真值只改 0.2%；真壁面速度：真值 6e-9，A 的原始分析 3.5e-2，EnKF 5.7e-8。
- 在 5 个验证 case 的完整循环（K=1，λ=0.3，32 样本）里：

| 变体 | 说明 | RMSE 均值 | 保存场散度 | 未投影样本均值散度 | 真壁面速度 |
|---|---|---|---|---|---|
| A0 | 不投影 | 0.0158 | 4.2e-2 | 4.2e-2 | 2.7e-2 |
| A1 | 采样后每个样本投影，投影场进入循环 | 0.0157 | 4.2e-7 | 4.2e-2 | 2.2e-8 |
| A2 | A1 + 引导里用 P(x̂₀) | 0.0155 | 4.2e-7 | 2.9e-2 | 2.2e-8 |
| A2l0 | A2 但 λ=0 | 0.0169 | 4.2e-7 | 5.7e-2 | 2.2e-8 |

  A1 对 A0：0/5 个 case 更差；A2 对 A1 改善极小（接近种子波动，主要来自 case 4）；去掉 λ=0.3 惩罚 5/5 更差，**投影引导不能替代散度惩罚**。**正式流程建议用 A1（λ=0.3）**，A2 只作消融，且只能称"带投影引导的 DPS"，不是严格的受约束后验采样。
- **散度的诚实表述**：原始口径 A 0.042 对 EnKF 约 5e-4（高约 90 倍）；两边用同一投影后都是机器精度，打平。公平口径下做不到"A 比 EnKF 低"；A 的优势在精度。报告要同时给原始和投影后两个口径，并写明 EnKF 投影后同样是 1e-7 量级。

### 2.5 EnKF 调优（验证 case 0，68 个配置）
- 新增 `demean_init`（初始扰动去均值，集合均值严格等于中心）和 `init_ensemble`（给定初始状态）。
- 局地化 1.5×1.2 实际接近全局（最远归一化距离 1.30，Gaspari–Cohn 到 2 才为零）。扫描 x 半径 0.15–1.0、z 半径 0.05–0.4、膨胀 1.00–1.15：**最优是膨胀 1.1、无局地化，RMSE 0.0250**（原设置 0.0278）；强局地化更差；膨胀 1.0 明显差。前几名之间差距小于种子波动。
- 初始化方式：用 20 个训练集快照（不同 case、随机时刻）起步，稳态 0.0250，和中心加扰动一样，全程均值略高（起步段，0.0262，3 次抽样波动约 0.0008）。
- EnKF 的 spread（0.013–0.018）小于实际误差（0.025），集合偏自信；未做系统的 spread–skill 诊断。

### 2.6 观测间隔 K（验证 case 0，3 个种子，全部帧 RMSE）
| K | A（λ=0.3，32 样本） | EnKF（调优） | 纯预报 |
|---|---|---|---|
| 1 | 0.0159 | 0.0257 | 0.0352 |
| 20 | 0.0323 | 0.0345 | 0.0352 |
| 50 | 0.0321 | 0.0350 | 0.0352 |
K=1 时 A 好 38%；K=20/50 时 A 仍好但只有 6–9%，两者都接近纯预报（观测稀疏、间隔长时主要由 Ra 失配决定）。A 与 EnKF 的参数都是在 K=1 下选的，没为长间隔重调。K=50 在 100 帧里只有 2 次观测。

### 2.7 5 个验证 case 的稳健性检查（K=1，种子 42）
A 0.0158，EnKF 0.0254（另一个候选配置 0.0259），纯预报 0.0411；A 在 5/5 个 case 上优于 EnKF，逐 case 改善 42/44/45/42/17%。case 4 是弱点（A 0.0222，纯预报最大 0.0518），原因未查。EnKF 两个候选配置没有稳定排序。

## 5. 方法层面的结论（别再重复论证）
- 精度：A 优于调优后的 EnKF（K=1 约 38%，5/5 个验证 case）；长间隔优势很小；Ra 接近真值时 EnKF 更好（旧记录）。
- 散度：公平口径下做不到 A<EnKF；A1 让 A 交付的场满足物理约束且无精度损失。
- 不要再靠加大 λ 或加数据/加大先验来降散度。
